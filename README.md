# نَسَق

معاينة تفاعلية لمتجر ملابس عربي ولوحة إدارته. يمكن فتح الرابطين مباشرة من الهاتف أو الحاسوب.

- [معاينة المتجر](https://notwork2.github.io/nasaq-preview/) — تصفّح الرفّ، جرّب الإطلالات وأكمل خطوات طلب تجريبي.
- [معاينة لوحة الإدارة](https://notwork2.github.io/nasaq-preview/admin/) — اطّلع على المنتجات والطلبات والمخزون ببيانات افتراضية للقراءة فقط.
