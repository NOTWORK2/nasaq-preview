# نَسَق

معاينة تفاعلية لمتجر ملابس عربي. يمكن فتح الرابطين مباشرة من الهاتف أو الحاسوب.

- [معاينة المتجر](https://notwork2.github.io/nasaq-preview/) — تصفّح رفّ الملابس والإطلالات، واطّلع على وسائل التواصل وسياسات المتجر.
- [معاينة لوحة الإدارة](https://notwork2.github.io/nasaq-preview/admin/) — تصفّح الطلبات والمخزون والرسائل ببيانات تجريبية.
- [تجربة إعدادات التواصل والسياسات](https://notwork2.github.io/nasaq-preview/admin/#settings) — عدّل الروابط أو نصّ الإرجاع واحفظ التغييرات، ثم افتح المتجر في المتصفح نفسه لترى النتيجة. تُحفظ تعديلات المعاينة على جهازك ويمكن استعادة القيم الأصلية.
